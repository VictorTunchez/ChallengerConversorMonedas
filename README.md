# ChallengerConversorMonedas
Este proyecto consiste en un conversor de monedas desarrollado en Java, que consume una API de tasas de cambio (Exchange Rate). El objetivo principal es reforzar conocimientos sobre:
Programación orientada a objetos
Consumo de APIs REST en Java
Manejo de entradas y salidas
Buenas prácticas de desarrollo ágil y documentación

Herramientas utilizadas: 
Java (JDK 17 o superior recomendado)
IntelliJ IDEA como entorno de desarrollo (IDE)
API Exchange Rate para obtener tipos de cambio entre monedas (Se requiere registro gratuito para obtener un api key)
